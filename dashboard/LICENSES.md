# Assets and dependencies

This website has no external runtime dependencies, remote fonts, embedded tracking, or third-party image assets. It uses system fonts, original SVG interface icons and charts, and hand-authored synthetic demonstration fixtures.

The user's AEGIS QUANT specification informed the website requirements. The source PDF is not distributed with the public hosting bundle. No licensed exchange feeds, current broker fee schedules, market datasets, or third-party model results are included.

The local preview server uses Node.js standard-library modules. Node.js is the user's local development runtime and is not bundled or required by the static hosting package.

Synthetic fixtures are for interface demonstration and pipeline exploration only. Provider integration would require separate checks of access permissions and permitted display, storage and redistribution terms.
